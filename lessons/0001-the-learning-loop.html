Lesson 1: The learning loop

Goal: understand how a large AI product becomes a sequence of small experiments you can explain.

The project is a ladder, not one task

“Build an inventory platform” is too large to execute directly. We turn it into observable behaviors: accept an image, validate it, detect objects, identify products, count them, and expose the result.

image → detection → identification → count → inventory event

What you will do every time

  1. Choose one behavior.
  2. Define what goes in and what comes out.
  3. Build the smallest implementation.
  4. Test success and failure.
  5. Run it on real examples.
  6. Measure and inspect mistakes.
  7. Decide the next change from evidence.
Important: a model that runs is not necessarily useful. A useful system tells us what it saw, how confident it was, where it fails, and what version produced the result.

Exercise

Open docs/PLAN.md. Explain in your own words why the first slice uses one image and 3–5 SKUs instead of a whole supermarket. Then run:

uv run pytest
uv run ruff check .
uv run mypy src

Ask questions about anything that is unclear. The next lesson will implement the first real behavior: a health endpoint and settings object.
