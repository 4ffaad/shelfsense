# Mission

Build ShelfSense while learning how to design, implement, evaluate, and explain a real computer-vision product.

The goal is not to finish a giant retail platform quickly. The goal is to repeatedly turn one measurable problem into working code, test it, inspect failures, and understand why the next change is justified.

## Learning contract

- We work in small vertical slices.
- You should understand each new file before moving on.
- I explain the reason for a design before implementing it.
- You run commands and inspect outputs; I do not hide the work behind generated code.
- Every vision claim is backed by examples and metrics.
- We prefer a small working system over premature infrastructure.
