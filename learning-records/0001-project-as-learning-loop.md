# Project as a learning loop

## Learned

ShelfSense is intentionally split into small observable behaviors. The first milestone is not “AI inventory”; it is a tested image-to-observation slice.

## Why it matters

Small slices make it possible to understand failures, measure progress, and avoid hiding complexity behind a large generated codebase.
